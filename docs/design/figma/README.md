# Макеты uCraft для uGym и uGym Business

[Открыть интерактивное превью](preview.html)

## Что внутри

| Страница | Содержание |
|---|---|
| uCraft | Палитра, типографика, иконки, варианты кнопок и полей, статусы, таблица и элементы системы |
| uGym | 16 экранов. Запуск, вход, подтверждение email, главная с абонементом, личный QR, каталог, расписание, визиты, тренировки и профиль |
| uGym Business | 19 экранов. Вход, ресепшн, операции, клиенты, касса, расписание, QR-сканер и планшетное QR-табло |

Основные экраны показаны в светлой и тёмной темах. Имена, суммы и QR-матрицы в примерах демонстрационные. Подключённые кнопки ведут между экранами макета.

## Редактируемый импорт в Figma Design

1. Создайте пустой файл в настольной Figma для macOS или Windows.
2. Выберите **Plugins → Development → Import plugin from manifest** и откройте [manifest.json](manifest.json) из этой папки.
3. Запустите **uCraft — uGym mobile boards** из меню **Plugins → Development**. Он создаст страницы **uCraft**, **uGym** и **uGym Business**, стили текста, варианты компонентов, переменные цвета и переходы. Установленные в Figma семейства Inter и Geist Mono используются в макетах. При ограничении на одну цветовую тему тёмные экраны импортируются с отдельными цветами.

[Импорт локального плагина в документации Figma](https://help.figma.com/hc/en-us/articles/38457121114263-Create-a-Figma-Design-plugin-with-the-Figma-MCP-server-and-agentic-tools)

Для просмотра на Linux откройте [превью](preview.html) в браузере. Кнопка **Скачать SVG** сохраняет выбранный лист для переноса на холст Figma. В SVG доступны векторные формы, а компоненты, темы и переходы создаёт локальный плагин.

[Импорт SVG в документации Figma](https://help.figma.com/hc/en-us/articles/360040028034-Add-images-and-videos-to-designs)

## Проверка и пересборка превью

Из корня репозитория запустите `node docs/design/figma/preview.js --check` для проверки границ, имён, вариантов компонентов и переходов. Команда `node docs/design/figma/preview.js` обновит `preview.html` из общего исходника макетов.
